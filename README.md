# Z-Imburse

Z-Imburse powers instant self-authorizing reimbursement through leveraging ZK Email and the Aztec Network.

The two classes of Z-Imburse users:

- Escrow managers: fund the escrow contract and set policies for reimbursement
- Grantees: use ZKEmail.nr to verifiably self-execute claims over entitlements to reimbursements on things like travel and hosting costs
